# 🚀 Composite Calling Skills Reference (`call-doc.md`)

This document serves as the master quick-reference for all **Composite Calling Skills** available in the `ai-skills` library. Instead of invoking 5–10 individual skill commands manually in conversation (e.g. `/skill1 /skill2 /skill3`), you can trigger a single composite skill (e.g. `/call-front` or `/call-backend`) to activate the complete suite of specialized patterns, architectural guardrails, and procedural rules for that domain.

## 💡 How to Use Composite Skills in Conversation

You can trigger any composite skill directly in your prompt:

```text
/call-doc document all files in this repository with header docstrings and inline function annotations
```

```text
/call-front build a dark-mode dashboard for tracking AI agent metrics
```

```text
/call-ai-ml build a vector search RAG pipeline using FastAPI and pgvector
```

```text
/call-backend refactor our user authentication service for high concurrency
```

```text
/call-arch propose a clean microservice architecture for our payments module
```

```text
/call-debug analyze why our API request latencies spike under load
```

The AI agent automatically loads and enforces the combined rules, guardrails, and best practices of all sub-skills bundled inside the command!
