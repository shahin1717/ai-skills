## ⚡ Core Directives & Playbook (Fast Path)

When `/call-build` is invoked, strictly enforce the following rules:

### 1. Test-Driven Development (TDD) First
- Write the failing test case before implementing functional logic.
- Run tests to verify the expected failure, then write minimal code to pass.

### 2. Anti-Overengineering Restraint (Ponytail / YAGNI)
- Do not build speculative abstractions or future-proofing that wasn't requested.
- Prioritize standard library / native platform capabilities before adding third-party dependencies.

### 3. Action-First & Dense Communication
- Lead with what changed, exact commands run, and test outcomes.
- Eliminate conversational fluff and redundant summaries.
